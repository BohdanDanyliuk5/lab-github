## Мета роботи
Опанувати базові навички роботи з Git і GitHub: створення репозиторію,
гілок, шаблону Pull Request, процесу code review.

## Теоретичні відомості
**Git** — розподілена система контролю версій. Основні поняття:
репозиторій, коміт, гілка (branch), злиття (merge), віддалений репозиторій (remote).

**GitHub** — вебплатформа для хостингу Git-репозиторіїв і спільної роботи.

**Pull Request (PR)** — запит на злиття змін з однієї гілки в іншу,
що дозволяє провести code review перед злиттям.

**Contributor** — користувач із правами на внесення змін у репозиторій.
**Reviewer** — користувач, який перевіряє зміни в PR та залишає Approve
або запит на зміни. **Assignee** — відповідальний за PR.

**.gitignore** — файл зі списком шаблонів файлів, які Git не відстежує.
**PULL_REQUEST_TEMPLATE.md** — шаблон опису PR, який автоматично підставляється
в нові запити.
